# Suresh Yadav — Premium Freelance Portfolio

A responsive, light editorial-style freelance portfolio built with HTML, CSS and JavaScript. The visual direction uses warm off-white, deep navy and burnt orange, inspired by the reference designs supplied by the user.

## Pages
- `index.html` — Home
- `graphic-design.html`
- `social-media.html`
- `content-writing.html`
- `b2b-lead-generation.html`
- `digital-marketing-branding.html`
- `about.html`
- `contact.html`

## Assets
- `assets/style.css` — responsive design system
- `assets/main.js` — mobile navigation and email-draft form
- `assets/config.js` — contact/social configuration
- `assets/profile.jpg` — add your portrait here (not included)

## Publish on GitHub Pages
1. Download and extract the ZIP.
2. Open your repository `imsureshyadavsocial-eng.github.io`.
3. Upload all files and folders to the repository root. Keep the `assets` folder intact.
4. Commit changes.
5. In `assets/config.js`, update LinkedIn URL if needed and check the email/WhatsApp number.
6. Upload your own portrait to `assets/profile.jpg`.
7. Open your GitHub Pages site and test all menu links on mobile.

## Adding projects later
Service pages include clearly labelled empty gallery slots. Replace the placeholder `<div class="gallery-slot">...</div>` elements with image tags, for example:
`<img src="assets/projects/my-project.jpg" alt="Short description of the project">`
Place your images under `assets/projects/`. Do not claim fictional concepts are real client work.

## Contact form
The form opens the visitor's default email app with a prefilled email. It does not store submissions on a server. A hosted form service is needed for true web-based form submissions.
